# M2 plan

M2 scope and its exit sentence are in [MVP.md](MVP.md). This file puts that scope in order. What has actually landed goes in `STATUS.md`.

**M2 is done when:** an end-to-end test edits one paragraph in an `.mdx` page containing JSX components, raw HTML and unusual frontmatter, and the resulting PR diff touches only that paragraph's lines; a non-GitHub user can propose a change that a GitHub user then merges, and the site updates.

## Order, and why

Build the lossless editor document bridge and dirty-block tracking first in `packages/doc-model` (pure, testable against the 595-file corpus), then build the draft + multi-file git write + 3-way merge layer, then wire the `propose` worker queue, `pull_request` webhooks, Sign in with GitHub, and Editor/Viewer roles, then mount the Editor SPA (`apps/editor` + `apps/server`), and finish with the M2 exit script (`pnpm m2:exit`).
